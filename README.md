# My First Static Website

A small learning project made with HTML, CSS, and Node.js.

## Run it

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. Open a terminal in this folder.
3. Run:

```powershell
npm.cmd start
```

If PowerShell allows npm scripts on your machine, `npm start` works too. `npm.cmd` is the Windows command version and avoids PowerShell execution-policy errors.

4. Visit <http://localhost:3000> in your browser.

## Project structure

- `public/index.html` contains the page content.
- `public/styles.css` contains the visual design.
- `server.js` serves the files with Node.js.
- `package.json` stores the project metadata and start command.
